FAQ

About pricing and fit

How are the prices set?

My rate is $60 an hour. Each package price is that rate times the hours the work normally takes, and the scope is written down before I start. If the work turns out bigger, I tell you before doing it.

Which service should I start with?

If something is broken or the numbers look wrong, start with an audit. If you want to see where revenue is quietly leaking, the hidden revenue insights dashboard. If you know what you need built, go straight to the build package. If you need ongoing senior help, the retainer.

Do you sign NDAs?

Yes. I also keep client names and internals out of my portfolio, as you can see on this site.
