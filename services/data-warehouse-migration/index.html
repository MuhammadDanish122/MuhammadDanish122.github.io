FAQ

Questions about this service

Which warehouse should we choose?

It depends on query patterns, data size, team skills and what you already pay for. The Assessment ends with a written recommendation. For a first rough cost comparison, try my free warehouse cost estimator.

Do you work with Databricks and Delta Lake?

Yes. I've built on Databricks and Delta, and led a move from Databricks, Azure SQL DW and ADF to Microsoft Fabric with OneLake Delta tables.

Do you write the infrastructure as code too?

I keep to the data layer and work with your infrastructure team's setup. I am not a Terraform specialist, and I won't pretend to be one on your production estate.

How do you know the new warehouse is right?

Both systems run in parallel. I compare row counts, id ranges and key measures table by table and report by report. Cutover happens only when they match, or when every difference is explained and signed off.

Can you just build dbt models on our existing warehouse?

Yes. The Starter warehouse works on Snowflake, ClickHouse, Fabric, Redshift, SQL Server or Postgres if the warehouse is already there.
